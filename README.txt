《富春江行：奇山異水》第一版

執行方式
1. 解壓縮資料夾。
2. 使用 Chrome 或 Edge 直接開啟 index.html。
3. 不需要網路，也不需要安裝伺服器。

操作方式
WASD／方向鍵：上下左右移動
J：墨筆攻擊
K 或空白鍵：閃避
L：消耗山水靈韻發動範圍技能
E：觀察游魚、細石或進入下一關
P：暫停
R：遊戲失敗時重新挑戰

目前內容
第一章：風煙俱淨（三線式橫向戰鬥）
第二章：從流飄蕩（乘船切換航道）
第三章：水皆縹碧（觀察游魚細石）
終戰：急湍猛浪（奔浪水獸首領戰）

設計說明
本遊戲為單一 HTML 檔，所有畫面、動畫與音效皆由程式即時產生，因此可直接離線執行，也適合上傳 GitHub Pages。
