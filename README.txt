《山水問心：富春江行》

執行方式
1. 解壓縮資料夾。
2. 使用 Chrome 或 Edge 直接開啟 index.html。
3. 不需要網路，也不需要安裝伺服器。

操作方式
WASD／方向鍵：上下左右移動；乘船時 A／D 或左右方向鍵掌舵、W／上方向鍵加速、S／下方向鍵減速；答題時以 W／S 或方向鍵選擇
空白鍵：斬擊、蓄力、觀察、收竿與場景互動
L：施展「山水清音」，震退主角身旁的精怪
空白鍵：尋聲關卡中重播山林聲音
P：暫停
R：遊戲失敗時重新挑戰
手機／平板：橫向使用裝置，以畫面方向鍵、攻擊鍵、清音鍵與暫停鍵操作

目前內容
第一章：風煙俱淨（三線式橫向戰鬥）
第二章：從流飄蕩（縮小的主人翁坐在船頭，駕武俠古典蓬舟閃躲水墨礁岩；水波沿水路延伸）
第三章：水皆縹碧（觀察游魚細石）
第四章：寒樹成韻（聆聽泉、鳥、蟬、猿的方位，點選山林尋找聲源）
終戰：急湍猛浪（奔浪水獸首領戰）

恢復心神
第一章、第三章與終戰的打怪路線各設兩枚七彩成語靈丹，依序標註「閒情逸致、賞心悅目、神清氣爽、怡然自得、逍遙自在、心曠神怡」。心神全滿時靈丹會留在原地；受傷後靠近即可自動服用並補血。

俠影清江垂釣
第三章觀察三尾游魚後會進入垂釣挑戰。釣線由畫中竹竿竿尖接出；以 WASD／方向鍵御線移動魚鉤，靠近游魚後按空白鍵提氣收竿。

寒樹尋聲
第四章會隨機播放資料夾內的流水聲、鳥鳴聲、蟬聲與猿叫聲四個音檔。聲音的左右方位會依畫面聲源位置計算，建議佩戴耳機；確認播放成功後才可點選畫面中的聲源。若瀏覽器阻擋首次自動播放，可點擊「播放聲音」或按空白鍵播放／重播。

終戰提示
奔浪水獸會轉身追蹤玩家，繞到背後仍會遭到反擊；遠程浪擊最多三枚並排，蓄力劍氣可以與浪擊互相抵消。擊敗水獸時，牠召出的妖怪會一併消散。

船程加分
乘船途中可用 W／上方向鍵持續加速、S／下方向鍵持續減速，並掌舵拾取「悠然自得、閒情逸致、逍遙自在」加分靈丹，每枚增加 260 悟境。錯過靈丹不影響通關。

章末小學堂
每一章完成主要挑戰後，靠近醒目的山水卷軸並按空白鍵，會進入「富春江風情畫小學堂」，連續回答五道《與宋元思書》題目。
